# Install OpenWorker

Install the SDK in your application project.

```sh
npm install @openworkerai/harness-sdk
```

npm installs the compatible native runtime automatically. Keep optional dependencies
enabled and commit your application's lockfile. The SDK runs in your Node server
or desktop application's trusted process; browser code calls your application's API.

For Rust setup, native platform requirements and release-specific compatibility,
see [versions and installation](releases.md).

Continue with the [Desktop app](desktop.md) or [Web app](server.md) walkthrough.
