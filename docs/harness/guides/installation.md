# Install OpenWorker

Install the published TypeScript SDK in your application with
`npm install @openworkerai/harness-sdk` (Node.js 20 or newer). It installs the
matching native runtime automatically; keep optional dependencies enabled.
The current SDK/runtime release is `0.1.0-beta.2`.

Start with the [Desktop app](desktop.md) or [Web app](server.md) track for the
installation command, optional Codex/Claude skill and a complete application example.
For Rust source setup and upgrading an existing application, see
[versions and compatibility](releases.md).
