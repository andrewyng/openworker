# Deployment input examples

`aws-infrastructure.json` is an offline test/review fixture. Its versions are not a
supported-version catalog; its guard bucket/version/digest do not identify an uploaded
package. It deliberately opts into disposable experiment data deletion. Do not treat
this file as approved production configuration.

See [the export guide](../../../docs/harness/OWS-AWS-INFRASTRUCTURE-EXPORT.md) for the
command, generated artifacts and remaining live qualification gates.
