# Resume Tweaks — Applied Data Fellowship (ADF), Harris School of Public Policy

**Target fellowship:** Applied Data Fellowship — 12-month full-time, embedded in local/state/local governments & nonprofits; competitive stipend + health-insurance reimbursement; open year-round (rolling review; external posting deadline 2026-12-26).

## 1. Put the ADI Fellowship and NRG at the front
For ADF the two most relevant resume items are:
- **Applied Data Institute (ADI) Fellowship** — the single strongest eligibility signal; name it in the opening and frame it as "data + ML under senior mentorship."
- **NRG market-research internship** — the policy-adjacency signal; reframe from "market research" to "policy impact analysis": you analyzed how *policy* trends shift *market demand and regulatory compliance* — that's policy analysis in the making.

Reorder so that ADI + NRG sit visibly near the top, ahead of the generic Hewani bullet, so a policy-screening reader lands on the "data + policy" story first.

## 2. Build an explicit "Data Skills" evidence line
The posting lists the fellow archetypes as Data Scientist/Analyst (Python, R, SQL, ML), Program Manager, and "Data Shaman." Add a crisp line that reads like the posting:
- **Data stack:** Python · SQL (PostgreSQL) · ML/LLMs (RAG, SLM agents) · vector & graph datastores (Neo4j, NetworkX) · visualization/BI (name any you've used, e.g., Streamlit) · R (beginner)
- Add a one-liner of output: "Built evaluation-first ML pipelines over sensitive insurance/health data."

## 3. Lead with the "builder who can operationalize" angle
ADF wants "builders… who can operationalize programs with data." Your Hewani "own end-to-end deployment, monitoring, and retraining" + Mutual of Omaha "RAG live and reducing manual review time" are the proof. Make these concrete and metric-oriented. ADF is about *getting the insight into use*, not research for its own sake — emphasize shipped, used systems over experiments.

## 4. Pre-empt the education gap honestly
The program "favors fellows from graduate programs in public policy, data science, economics, social sciences, CS." You have **no graduate (or undergraduate) degree listed**. Two honest options:
- **Do not fabricate a degree.** Instead, let the ADI Fellowship (a supervised, selective applied-data program) carry the "equivalent rigorous data training" argument — you already name it, so lean on it.
- If you *do* hold a bachelor's or some completed coursework anywhere, and it's true, add it under Training/Certifications. If you genuinely have none, the resume stays as-is and the cover letter makes the "equivalent experience" case (which this draft already does).

## 5. De-emphasize (lightly)
- **Snap Inc. storytelling** and the **quantum RNG project** are the two least-relevant items for a public-policy-data fellowship. Keep them brief; they show range but are not the lead.
- The **Hybrid QML / Hetionet project** is still useful (data on a biomedical knowledge graph + evaluation) — keep, but frame as "data + ML + evaluation," not "quantum research."

## 6. Timing
This is **rolling**, so it's not deadline-critical — submit early in the window and tailor one more line per partner you might be matched with. No urgency this run.
