## Infrastructure note

The Qdrant instance at `localhost:6333` (v1.19.0 docker container, data in `~/.qdrant`) has a non-standard HTTP API: **POST** `/collections/default/points` silently accepts anything and discards it (claims success, no write) — I lost significant time to this. The working upsert is **PUT** `/collections/default/points` with the standard `{"points":[…]}` body (named vector). Scroll/count/read-by-ID/delete all work on their standard POST endpoints; the search endpoint rejected every request shape tried, so retrieval verification was done via scroll. `store_corpus.py` encodes the working shape, and I saved a permanent memory of this quirk.
