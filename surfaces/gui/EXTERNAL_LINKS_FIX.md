## 一、现象

桌面客户端（Tauri v2 壳，macOS）对话中收到的网址链接：
- 左键点击 → 无反应
- 右键 → Open Link → 无反应

浏览器 dev 环境正常，只有桌面壳失效。

## 二、根因（两层，v2 才定位全）

### 1. 左键无反应 — ACL 权限缺失（v2 根因，v1 未解决）

v1 只在 `capabilities/default.json` 加了 `opener:allow-default-urls`，但 Tauri v2 的 ACL 分两层：

| 权限 | 作用 |
|---|---|
| `opener:allow-open-url` | **授权 `open_url` 命令本身**（`commands.allow = ["open_url"]`） |
| `opener:allow-default-urls` | 仅提供 URL 白名单 **scope**（http/https/mailto 等），不授权命令 |

前端 `openUrl()` 的 invoke 因缺少 `allow-open-url` 被 ACL 拒绝，返回 `Forbidden` 错误；而 `openExternal()` 的 `.catch()` 只做静默 fallback（`window.open` → 在 WebView 里同样被丢弃），所以表现为"点了没反应"，无任何可见错误。

**证据**（`tauri-plugin-opener-2.5.4` 源码）：
- `src/commands.rs`: `open_url` 命令有 `CommandScope` 参数 → 命令必须被授权
- `permissions/autogenerated/commands/open_url.toml`: `allow-open-url` = 授权命令；`allow-default-urls` 仅 scope

### 2. 右键 Open Link 无反应 — 未处理"新窗口"请求

`target="_blank"` 链接（Markdown 渲染均为 `_blank`）在 macOS WKWebView 中：
- 右键 Open Link 走 `webView:createWebViewWithConfiguration:...`（**新窗口请求**）
- **不经过** `on_navigation` 回调（v1 只实现了 on_navigation）
- 壳未注册 `on_new_window` → wry 静默丢弃（上游 issue #227/#270 同源问题）

**证据**（`wry-0.55.1` 源码 `src/wkwebview/class/wry_web_view_ui_delegate.rs`）：
- `create_web_view_for_navigation_action` 调 `new_window_req_handler`（即 Tauri 的 `on_new_window`）
- `NewWindowResponse::Deny => None`（L255）

## 三、修复内容

### 文件改动（3 个，5afc3f2 + 日志）

1. **`surfaces/gui/src-tauri/capabilities/default.json`**
   ```json
   "opener:allow-open-url",      // ← 新增：授权 open_url 命令
   "opener:allow-default-urls",  // URL scope 白名单
   ```

2. **`surfaces/gui/src-tauri/src/lib.rs`** — 新增 `on_new_window` 处理器
   ```rust
   .on_new_window(|url, _features| {
       eprintln!("[openworker] on_new_window: {url}");
       if matches!(url.scheme(), "http" | "https" | "mailto") {
           let _ = tauri_plugin_opener::open_url(url.as_str(), None::<&str>);
       }
       tauri::webview::NewWindowResponse::Deny
   })
   ```
   并给 `on_navigation` 加 `eprintln` 日志。

3. **`surfaces/gui/src/tauri.ts`** — `openExternal` 加 console 日志（定位用）

### 三重保险链路（v2 后）

```
左键点击 → JS preventDefault → opener.openUrl（ACL 已授权 ✓）
              └─ 万一失败 → window.open fallback → 原生 on_new_window
右键 Open Link → WKWebView createWebViewWith → 原生 on_new_window
on_new_window → tauri_plugin_opener::open_url → 系统默认浏览器 ✓
```
