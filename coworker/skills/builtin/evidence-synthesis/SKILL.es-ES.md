# Síntesis de evidencias

Usa esta habilidad para convertir varios informes en una síntesis lista para decidir.
Clasifica cada afirmación como evidencia directa, inferencia o afirmación sin respaldo.
Conserva el disenso y las contradicciones relevantes; no inventes votos, quórum, consenso
ni certeza numérica.

Devuelve acuerdos, disenso, referencias de evidencia, una valoración de confianza en
lenguaje sencillo, una recomendación y preguntas sin resolver. Indica qué observación
cambiaría la recomendación. El líder valida y decide; la síntesis es evidencia, no autoridad.
